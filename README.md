# 😂 Life as a Software Engineer

### The five stages of debugging

```text
1. "This should work."
2. "Why isn't this working?"
3. "That makes absolutely no sense."
4. "Ohhhhh, I see."
5. "How was this ever working before?"
```

### My relationship with bugs

```python
while bugs_exist:
    investigate()
    debug()
    fix()
    test()

    if new_bug_appears():
        print("Interesting plot twist. 😭")
```

### Things developers understand

- A five-minute fix can become a three-hour investigation.
- The best ideas sometimes arrive after closing the laptop.
- Naming variables is harder than it should be.
- `git status` is a lifestyle.
- Documentation is a love letter to your future self.
- "It works on my machine" is not a deployment strategy.
- Sometimes the most productive thing you can do is take a walk.

# 🧠 My Engineering Philosophy

I don't believe great software is measured by how many lines of code you write.

I believe it's measured by:

**The problems it solves.**

**The people it helps.**

**The reliability it delivers.**

**The experience it creates.**

And the ability of another developer to understand the code six months later without questioning every life decision that brought them there.

### Principles I Try to Follow

**01 — Simplicity wins.**

Complexity should be justified, not celebrated.

**02 — Build for humans.**

The best technical solution is useless if people cannot use it.

**03 — Security is a responsibility.**

Protecting user data is part of engineering, not an optional feature.

**04 — Learn continuously.**

Technology evolves. Engineers should too.

**05 — Deliver value.**

Software should solve real problems, not merely look impressive in a demo.
